# Expanding Horizon Journal

Independent international multidisciplinary academic journal website.

## Website foundation

This repository contains the static launch foundation for Expanding Horizon Journal, including the homepage, mission and scope, author guidance, reviewer guidance, editorial governance, policies, archives, article template, access and copyright, privacy, contact pages, and the journal visual identity assets.

## Launch status

This is a website foundation. Before production publication, replace placeholders, confirm ownership and editorial roles, obtain or confirm ISSN, establish the manuscript submission and peer review workflow, finalize legal and privacy notices, and add only verified identifiers and indexing information.

## Deployment note

The main branch is the website source of truth. New commits should trigger the connected hosting deployment when the hosting integration is active.
